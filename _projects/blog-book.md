Blog Book is a Python and Django blogging platform with authentication and role-based content management. It brings authoring, reader interactions, and moderation into one application.

## Publishing and interaction

- Create, edit, and delete blog posts.
- Participate through threaded comments and likes.
- Follow content through subscription workflows.

## Backend and moderation

An administration dashboard supports moderation and content lifecycle management. The backend uses Django routing and the Django ORM for database interactions.
