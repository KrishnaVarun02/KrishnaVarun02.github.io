Rent-a-Bike is a bike reservation platform built with Spring Boot and MySQL. An MVC architecture separates the application interface, service logic, and relational data operations.

## Customer features

- Search for bikes and make reservations.
- Manage bookings and review booking history.
- Generate invoices for booking transactions.

## Administration

Administrative functions support inventory management, pricing updates, and centralized booking monitoring. MySQL stores the application's reservation and inventory data.
